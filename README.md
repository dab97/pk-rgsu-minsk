# Мониторинг конкурсных списков РГСУ

Веб-приложение для отслеживания приёмной кампании Российского государственного социального университета (РГСУ) в реальном времени.

## Возможности

- **Бюджет и Платное** — переключение между основами приёма, направления с собственными конкурсными списками.
- **Конкурсные списки** — все абитуриенты с баллами, согласиями/договорами, приоритетами и преимущественным правом.
- **Моя позиция в конкурсе** — поиск по коду, место, сравнение с проходным баллом.
- **Распределение конкурсных баллов** — кто сколько набрал, с подсветкой диапазона проходного балла и точным значением по наведению.
- **Демо-режим** — при недоступности сервера РГСУ используются встроенные демонстрационные данные.

## Технологии

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- shadcn/ui (Radix UI, class-variance-authority)
- Express 5 + Cheerio (парсинг списков на сервере)

## Запуск локально

```bash
npm install
npm run dev
```

Сервер: `http://localhost:3000`

## Скрипты

| Команда           | Описание                          |
| ----------------- | --------------------------------- |
| `npm run dev`     | Запуск dev-сервера (Express + Vite) |
| `npm run build`   | Сборка клиента и сервера в `dist` |
| `npm start`       | Запуск собранного сервера          |
| `npm run lint`    | Проверка типов (tsc --noEmit)      |

## Структура

```
src/
  App.tsx            # вся логика интерфейса
  data.ts            # направления и демо-данные
  components/ui/     # shadcn/ui-компоненты
  lib/utils.ts       # cn() — утилита классов
server.ts            # Express-сервер и парсер списков
```
